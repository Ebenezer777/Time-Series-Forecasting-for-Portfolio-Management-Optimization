## Business Objective
Guide Me in Finance Investments aims to enhance portfolio performance using time series forecasting on:

- TSLA – High-growth stock
- BND – Bond ETF
- SPY – Market ETF

## Task 1 – Data Preprocessing & EDA

### Data Source
Historical data was downloaded using YFinance from 2015-01-01 to 2026-01-15.

### Data Cleaning
- Missing values handled using forward fill
- Data types verified
- Separate CSV files saved for each asset

### Key Observations
- TSLA shows strong growth with high volatility
- BND is stable with low variance
- SPY shows steady long-term growth
